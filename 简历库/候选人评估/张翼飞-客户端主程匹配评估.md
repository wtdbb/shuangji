# 张翼飞｜客户端主程匹配评估

关联简历：[[简历库/张翼飞.pdf]]

## 结论

**如果是自研引擎、Unity／C#或MMORPG客户端主程，匹配度可到90%左右，能力上可以胜任，甚至职级可能偏低；如果是UE4／UE5客户端主程，匹配度约60%—70%，不建议按高匹配推荐。**

公开文件能够确认他曾任上海美峰数码CTO，此前还担任过两家公司的合伙人／CTO，并有客户端工程师经历；另一份公开评估文件也记载其开发过多款大型多人在线游戏引擎、开发工具和编辑器并担任主程。因此，他并非只有“技术总监”头衔，历史上确实做过客户端、引擎和主程工作。

## 为什么能做客户端主程

- 约20年游戏开发经历，做过客户端、引擎、服务器和工具；
- 自研过玩法框架、战斗框架、AI行为树和多类编辑器；
- 熟悉MMORPG、ARPG、卡牌、MOBA等项目结构；
- 具备网络通信、客户端表现、资源管理和前后端整体架构经验；
- 有CTO及团队管理背景，能够承担技术方案和研发组织工作。

## 主要风险

1. **UE经验不足：** 简历写的是默认支持Unity，UE主要通过Unreal CLR扩展，没有体现使用UE原生C++完成商业项目；
2. **近年经历不清楚：** 简历缺少完整公司时间线、具体项目名称和最近数年的任职情况；
3. **可能过度定级：** 做过CTO，再应聘客户端主程可能涉及职级、汇报关系和薪资接受度；
4. **动手状态未知：** 需要确认目前是否仍持续写核心代码，而不是只做方案、管理和对外包装；
5. **学历门槛：** 大专学历，部分严格要求本科的公司可能直接卡掉；
6. **数据需要核实：** 月流水过亿、百万人在线、App Store第一等内容没有在简历中对应到具体项目。

## 按岗位类型判断

| 岗位 | 估算匹配度 | 建议 |
| --- | ---: | --- |
| 自研引擎MMORPG客户端主程 | 92% | 可以重点推 |
| Unity／C#客户端主程 | 90% | 可以推，确认Unity实际项目和动手状态 |
| 客户端技术总监／架构负责人 | 90% | 职级更匹配 |
| UE4／UE5客户端主程 | 60%—70% | 缺少原生UE商业项目证据，不建议硬推 |
| 纯Gameplay业务主程 | 75%—80% | 有玩法框架，但需确认最近是否直接负责业务交付 |

## 推荐前必须核实

1. 最近十年的公司、项目、任职时间及离职原因；
2. 最近三年亲自编写的代码、使用的语言和引擎版本；
3. 是否真正带过完整客户端团队从立项做到上线；
4. 月流水过亿及百万人在线分别对应哪个项目；
5. Unity或UE项目中实际负责的客户端业务模块；
6. 为什么从CTO／技术总监考虑客户端主程岗位，以及职级和薪资接受度。
