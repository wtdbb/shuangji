# 游勇｜Unity客户端工具链推荐报告

Hello，下午好，推荐一位 Unity 客户端工具链开发——游勇，辛苦评估：

1. 推荐理由：南昌大学数字媒体技术本科，具备多年 Unity 客户端开发经验，近年的工作重点偏向策划配置工具、运营内容配置与研发流程提效。在《舞力全开手游》中，主导以 Unity Editor 扩展结合 Web 运营后台的可视化配置工具建设，覆盖曲目、判定参数、难度曲线、活动与商品配置，支持策划自助配置及编辑器内试玩验证；同时搭建 Excel/表格导入、数值越界及引用完整性校验、热更一致性拦截、一键生成 ScriptableObject/JSON 数据的配置流水线，将配置上线周期由 3 天缩短至 1 小时、配置错误率降低 90%。此外，他有 Addressable 热更新、灰度发布、A/B 实验及 CrashSight 质量监控的上线后迭代经验；早期亦开发过基于时间轴与事件的技能编辑器、Buff 等策划配置工具，并使用 Python、Jenkins、Airtest/STF 参与工作流自动化和测试设备管理。整体与岗位的 Unity 编辑器工具、内容生产工具链、资源/配置检查及流程标准化方向较匹配。
2. 薪资：当前 40K，期望面议。
3. 看机会原因：当前项目已进入运营期，希望了解外部是否有更好的发展机会。
4. 期望城市：待沟通。
