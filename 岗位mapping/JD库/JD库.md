# JD库

用于集中保存岗位 JD，并给每个岗位标注**主方向、细分方向和一句话定位**，方便快速判断人选是否匹配。

## 目录规则

- `策划/`：系统、数值、战斗、关卡、文案、AI、运营活动等策划 JD。
- `程序/`：客户端、服务端、引擎、渲染、工具、性能优化等程序 JD。
- `美术/`：原画、3D、动作、特效、TA、UI 等美术 JD。
- `测试/`：功能测试、测试开发、性能测试、测试管理等 JD。
- `运营/`：产品运营、活动运营、用户运营、发行等 JD。
- `其他/`：暂时无法归入上述方向的 JD。
- `模板/`：新增 JD 时复用的格式。

## 岗位列表

```dataview
TABLE WITHOUT ID
    file.link AS "岗位",
    公司 AS "公司",
    城市 AS "城市",
    主方向 AS "主方向",
    细分方向 AS "细分方向",
    一句话方向 AS "一句话介绍"
FROM "岗位mapping/JD库"
WHERE 类型 = "JD"
SORT file.mtime DESC
```

## 方向判断原则

优先按岗位实际交付内容判断，而不是只看岗位名称：

- **Gameplay**：玩家操作、角色能力、战斗规则、交互与手感等综合玩法。
- **Boss**：Boss 机制、阶段、技能组合、战斗节奏及体验调优。
- **生态**：开放世界中的动物、NPC、群落、环境交互和涌现行为。
- **性能优化**：CPU、GPU、内存、加载、网络、包体、帧率和卡顿治理。
- **系统**：任务、背包、养成、社交、商业化等功能规则和流程。
- **工具／编辑器**：为策划、美术或测试提升内容生产效率。

同一 JD 可以有多个细分方向，但只选择一个最能代表核心工作的主方向。
