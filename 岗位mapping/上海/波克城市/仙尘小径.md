# 仙尘小径

波克城市旗下的轻度 Merge + 场景改造项目。公开资料显示，玩家通过合成物品获得资源，再逐步解锁和修复场景，让区域从简陋、荒芜变得完整繁华。

## 故事线判断

- **能确认的主线骨架**：合成物品 → 获取改造资源 → 修复/装扮当前区域 → 解锁场景模块和下一段内容。
- **用户口径（2026-07-24）**：项目主要由剧情推动，Merge 是推进剧情的任务和资源门槛。
- **叙事循环**：人物关系或剧情冲突抛出目标 → 玩家完成 Merge 订单/收集资源 → 修复场景或解决事件 → 解锁下一段对话和章节。
- **公开信息边界**：目前公开渠道没有完整披露角色姓名、人物关系、章节冲突和结局，无法可靠整理到具体人物剧情；网上部分“仙侠大战、御剑飞行”介绍与实际 Merge 改造玩法冲突，不宜采用。

## 文案量判断

- 既然是**剧情推动型 Merge**，角色对话并不少，更可能是“单段较短、出现频率高”，持续用悬念、人物关系和阶段冲突拉动玩家完成合成任务。
- 文案工作会覆盖章节剧情、人物对话、场景改造包装、任务引导、道具及系统命名、活动和商业化短文案。
- 它不同于 RPG 的长篇世界观叙事，更接近《Gossip Harbor》一类“短对话 + 强钩子 + Merge 卡点”的推进方式。

## 项目信息

- 2025 年 2 月获得国产游戏版号，申报类别为“移动—休闲益智”。
- 出版单位：波克科技集团有限公司。
- 运营单位：世熠网络科技（上海）有限公司。
