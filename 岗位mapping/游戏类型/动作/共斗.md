# 共斗

## 说人话

共斗就是**几个人一起打一个强目标/一场高压战斗**，重点不是刷小怪，而是多人协作围猎大型 Boss 或高难敌人。

## 核心特征

- 多人组队，通常 2-4 人，也可扩展到更多人。
- 目标通常是大型怪物、Boss、精英敌人或高难副本。
- 战斗重心在动作操作、职业分工、走位、仇恨/控制/输出节奏、资源管理。
- 常见循环：接任务/进图 → 追踪/探索 → 打 Boss → 掉材料/装备 → 做新装备 → 挑战更强目标。

## 典型参照

- 《怪物猎人》：最典型的共斗。
- 《讨鬼传》《噬神者》：传统共斗动作。
- 国内项目常写：开放世界共斗 ARPG、多人共斗 ARPG、Boss 共斗、狩猎共斗。

## 和其他品类区别

- 和 MMO 副本：共斗更强调动作操作和 Boss 狩猎，MMO 副本更强调职业铁三角、机制流程和团队规模。
- 和刷宝 ARPG：共斗更强调共同打强敌，刷宝更强调清怪效率和装备 Build 循环。
- 和搜打撤：共斗目标是合作打怪，搜打撤目标是带资源活着撤离，且常有强 PVP 压力。

## 岗位判断

适合看：战斗策划、关卡策划、AI策划、动作设计、Boss设计、客户端战斗、服务器同步、TA/动画等。
