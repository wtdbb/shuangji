# 杭州字节项目盘点

## 江南工作室

- [[朝夕光年（杭州江南工作室）/星球：重启|星球：重启]]：科幻开放世界生存射击，已上线、持续运营。
- [[朝夕光年（杭州江南工作室）/托托比亚（代号Atom）|托托比亚（代号：Atom）]]：欢乐动作冒险 + 多人派对 + UGC 编辑器；2026 年 5 月取得版号，尚未正式上线，是当前招聘最活跃、公开信息最明确的新项目。
- [[朝夕光年（杭州江南工作室）/三体IP游戏|三体 IP 游戏]]：写实科幻向在研项目；未公布正式名称，近一年没有明确进展。
- [[朝夕光年（杭州江南工作室）/PVE射击项目|PVE 射击项目]]：未公开代号；公开招聘出现竞技／搜打撤、写实科幻等关键词，但与三体项目是否同一条线无法确认。

> 原 J5 开放世界 ARPG 团队已于 2023 年并入腾讯萨罗斯，不再属于杭州字节项目。

## 心光工作室

- [[朝夕光年（杭州心光工作室）/高能手办团|高能手办团]]：3D 二次元放置卡牌，已上线、持续运营。
- [[朝夕光年（杭州心光工作室）/飞吧龙骑士|飞吧龙骑士]]：飞行射击 + Roguelike，已上线。
- [[朝夕光年（杭州心光工作室）/镭明闪击|镭明闪击]]：3D 成女二次元塔攻／即时策略 RPG，2026-05-15 公测。
- [[朝夕光年（杭州心光工作室）/烣境|烣境]]：原旗舰级二次元项目，公开报道口径为基本暂停。
- 另有未公开 RPG 和 AI 玩法探索；现有招聘包括 AI 玩法策划、关卡策划等，尚不能对应到确定项目名。

## 游戏 AIGC 部门

不是单独游戏项目，主要服务游戏研发管线：模型、贴图、动画、场景、剧情、对话、玩法生成，以及 3D 资产和 Agent 化提效。

## 招聘识别口径

- JD 写“江南 + 派对／UGC／编辑器”→ 基本对应《托托比亚》。
- JD 写“江南 + 写实科幻／PVE／射击”→ 可能对应三体 IP 或未公开射击项目，必须向业务方确认。
- JD 写“心光 + 二次元／AI 玩法／关卡”→ 多半是心光的运营项目或未公开新项目。
