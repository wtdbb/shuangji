# 虚环

## 一句话

腾讯 CDD 自研的 V 圈题材 3D 策略养成游戏：把现实中的女性虚拟主播做成“战斗偶像”，玩家负责养成、配队和战术构筑，战斗偏自动演出与中途微操，不是传统 ARPG。

## 项目与团队

- **研发团队**：腾讯 IEG 内容生态部 CDD，非天美、光子、魔方、北极光等传统工作室群。
- **地点**：公开招聘岗位主要在深圳。
- **立项时间**：2023年。
- **引擎**：Unity。CDD 原有较强的 UE 虚拟人和实时内容管线积累，但《虚环》为了移动端与 PC 多端适配选择 Unity。
- **题材**：V 圈 / VUP / 虚拟偶像；角色原型来自现实中的女性虚拟主播，由本人配音并保留原有性格和口癖。
- **核心结构**：角色养成互动、剧情与舞台演出、战斗表演。
- **战斗理解**：战前配队和 Build 构筑 + 自动战斗演出 + 战中暂停/微操；可理解为“赛马娘式养成 + 自走棋/圣兽之王式策略构筑 + V圈角色演出”。
- **商业化**：项目组曾明确不走传统角色抽卡和单纯卖数值路线，但最终商业化方案仍需以正式上线版本为准。

## 时间线

- **2024-08-04**：首支 PV 公布。
- **2025-08-04**：发布 PV02 与约21分钟实机演示。
- **2025-10**：光芒（刘智鹏）加入游戏科学，继续以顾问身份支持《虚环》。
- **2026-03-24—03-30**：开展“初见回”首次小规模删档保密测试，仅开放 Android。
- **截至2026-07-14**：仍处于研发和优化阶段，未查到正式公测日期。

## 首测表现与风险

### 优势

- V 圈角色的“活人感”、本人配音、表情与长演出是最强差异点。
- 战斗视觉上像动作游戏，实际是策略构筑，演出表现力较强。
- 题材和内容生态独特，腾讯 CDD 在虚拟人、动捕、实时演出及主播合作上有积累。

### 当前问题

- 首测移动端优化一般，对设备配置要求较高。
- 玩法维度多，前期引导不够清楚，理解门槛偏高。
- 首测内容量偏少，数值难度与整体玩法仍有调整空间。
- 使用真实主播 IP，长期需要处理停播、毕业、塌房、版权与多机构协作等风险。

## 技术与招聘画像

从公开招聘看，项目技术侧重点包括：

- Unity 客户端性能优化：CPU、内存、功耗、I/O、闪退和多平台兼容。
- Unity 源码改造、渲染性能、跨平台适配与性能工具链。
- C++ 后台开发、客户端/服务端稳定性。
- 技术美术、渲染表现、美术资源规范及生产管线工具化。
- 大量高质量角色、动画、镜头和演出内容的生产效率与移动端承载。

因此它不是纯内容型小团队，当前明显还在补强 **Unity性能、多端适配、渲染/TA、后台和研发管线**。

## 人才判断

- **客户端/引擎**：优先 Unity 深度优化、源码改造、移动端性能、多端适配、渲染管线背景。
- **TA**：偏渲染 + 工具/Pipeline 的复合型 TA 更匹配，不是只做纯美术资源。
- **策划**：策略构筑、养成、卡牌/自走棋、二次元角色塑造经验更匹配；纯 ARPG 战斗策划不一定直接对口。
- **项目风险**：新团队跨入完整游戏研发，首测仍暴露优化和引导问题；但腾讯资源、CDD虚拟人技术和V圈合作能力是明显优势。
