# 灰境行者

（猎杀夺宝 FPS·在研）：腾讯北极光的 UE5 PvEvP FPS 项目，微恐/克系/新怪谈氛围，玩法上接近《猎杀：对决》这类 Hunt-like：PVE 打怪 + PVP 抢夺 + 搜刮撤离。

## 说人话

- 像的地方：几队人进危险地图，里面有怪也有其他玩家，一边打怪搜东西，一边防别人偷袭，最后活着带资源出来。
- 和《猎杀：对决》的区别：
  - 《猎杀：对决》更像“找 Boss → 打 Boss → 抢赏金 → 撤离”，节奏慢、压迫、硬核。
  - 《灰境行者》更像“打怪发育 → 职业/天赋成长 → 抢宝/决战”，节奏更快、更游戏化。
- 一句话：国产 Hunt-like，但更强调局内发育、职业天赋和夺宝对决。
